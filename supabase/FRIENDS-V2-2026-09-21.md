# Cove Friends v2 (hosted) — September 21, 2026

Applied to the live Catmint Cove project (`gbkkiejmqocbijhnzoxg`) through the Supabase SQL editor with the owner's approval: `migrations/20260921_friends_v2.sql`. One transaction; adds `neo_cove_cards`, `neo_gifts` and the `neo_friends2(action, payload)` function (authenticated only, RLS on, no direct table grants).

Actions: `state`, `find` (exact code or `Name#tag`, 30 searches/day), `publish_card` (sanitised, 10s throttle), `gift` (50/100/250/500/1000, 1,000 sent/day), `love` (10 Shells to the friend, 3/day), `card` (6 fixed messages x 4 colours, 1 per friend per day), `claim` (atomic; an item can only be claimed once). Recipients can receive at most 2,000 Shells/day from all senders. Only accepted friends can gift, and blocking removes the friend.

Shells are never held by the server: the sender's device spends after the server accepts, the recipient's device credits after a successful claim. A modified client can therefore send gifts without paying, bounded by the daily caps above. Server-side balances would be needed to close that fully.

Tests: `node scripts/test-friends2-live.mjs` (47 hosted API checks, throwaway anonymous accounts). Two real browser sessions (join, find by code, invite, accept, visit, heart, gift, card, collect, reload) passed against the hosted project. Physical iOS and Android device checks are still outstanding. `?friends=preview` opens the local sample circle for design and QA.
